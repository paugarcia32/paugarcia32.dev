## Project Overview

Pulse Notch is a native macOS app that turns the MacBook notch into a compact activity surface. I built it for my own workflow: I wanted to know when a coding agent or GitHub Action finished and keep my next calendar event nearby without adding more notifications. The surface stays small until expanded, and it also works on Macs and external displays without a physical notch.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| App and interface | Swift 6, SwiftUI, AppKit |
| Build and tests | Swift Package Manager, Swift Testing |
| GitHub integration | Authenticated GitHub CLI (`gh`) |

Domain behavior lives in `PulseNotchCore`, while `PulseNotchApp` contains the macOS interface and integrations. The project uses Swift 6 strict concurrency checking.

## Privacy and Availability

Pulse Notch processes activity locally and includes no telemetry. Agent detection reads process and session metadata rather than conversation contents. GitHub activity uses the authenticated `gh` CLI, and integrations can be disabled individually in Settings.

It runs on macOS 14 Sonoma or newer. Apple Silicon builds are available through [Homebrew](https://github.com/paugarcia32/pulse-notch#installation) and the [latest GitHub release](https://github.com/paugarcia32/pulse-notch/releases/latest).
